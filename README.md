# 👟 STRIDE — Advanced Footwear Systems

A modern and futuristic **performance footwear website** designed for athletes and users who value speed, technology, comfort, and precision.

**STRIDE** combines a sleek tech-inspired interface with product collections, performance specifications, motion analytics, diagnostics, and interactive product experiences.


### 2. Open the project folder

```bash

```

### 3. Run the project

Open `index.html` directly in your browser.

For development, you can also use **VS Code Live Server**.
